# 项目说明

本目录整理自 Andrew Ng 在 Coursera 开设的 [Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) 配套资料，包含三门课程的中文讲义、编程作业及运行所需的代码、数据和图片。

请从 [中文学习目录](README.md) 按课程与周次学习。建议先独立完成练习，再查看参考实现；课程作业应遵守 Coursera 的学术诚信要求。

## 课程组成

1. **监督学习：回归与分类**：线性回归、逻辑回归、梯度下降、正则化。
2. **高级学习算法**：神经网络、模型评估、偏差与方差、决策树及树集成。
3. **无监督学习、推荐系统与强化学习**：聚类、异常检测、推荐系统、PCA 与深度 Q 学习。

术语采用情况见 [英中术语表](术语表.md)，公式、链接和逐文件检查结果见 [校对报告](校对报告.md)。
